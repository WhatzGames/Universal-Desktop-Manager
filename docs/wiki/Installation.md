# Installation

No packaged release or system installer exists yet. To try the source build, install
Rust 1.99.1 on a development machine and follow [Getting Started](Getting-Started).
Run the default report as a regular user. Experimental v0.2 package commands are
separate; see [Installing Desktops](Installing-Desktops). The approved disposable VM installation suite passed; physical hardware
and primary-desktop support remain unvalidated.
An offline Linux test artifact is for development validation, not a supported release.
