# KDE Plasma

The catalog includes KDE Plasma Wayland even when it is not installed. Only Debian 13
queries the local APT cache. Available means a candidate was found, not that installation
or Wayland will work. The v0.2 development branch can simulate a complete Debian 13
KDE transaction and verify installed packages and launcher. The approved disposable VM suite passed installation, original desktop continuity
and isolated KWin/Plasma readiness; physical GPU/input remain unvalidated. UDM does not start Plasma.
A future custom Plasma-inspired shell is different from real KDE Plasma/KWin.
