# Universal Desktop Manager

UDM is experimental. Its current command prints a read-only report of host basics,
standard session entries and KDE status. Installation, graphical management and
switching are planned, not available. Start with [Getting Started](Getting-Started),
[First Launch](First-Launch) and [Quick Start](Quick-Start). See [Supported Desktops](Supported-Desktops)
and [Known Limitations](Known-Limitations) for the scope of tested behavior.

The sidebar links the complete initial manual, including planned installation and
switching behavior, settings, troubleshooting and FAQ.
